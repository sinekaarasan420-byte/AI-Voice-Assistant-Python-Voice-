# 🎙️ AI Voice Assistant in Python

An automated voice assistant built with Python that listens to voice commands and performs tasks like setting alarms, opening applications.

---

## ✨ Features

- **Voice Recognition:** Listens to microphone input and converts speech to text.
- **Text-to-Speech:** Provides natural audio responses using speech synthesis engines.
- **Task Automation:** 
  - Opens popular desktop apps.
  - Controls basic system commands.
